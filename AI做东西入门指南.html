AI做东西入门指南

零基础也能用AI做出自己的工具 · 2026年最新版

💡先搞懂一件事

2026年了，做东西不需要会写代码。你只需要做两件事：

① 用嘴描述需求→② AI帮你做出来

就像你跟装修师傅说"我要一个三室一厅、主卧朝南、厨房带岛台"，师傅就给你盖出来了。AI就是那个师傅，你是说需求的人。

核心秘诀：需求说得越详细，AI做得越准。比如别说"做个网站"，要说"做一个记账App，有收入和支出分类，能看月度统计图，深色主题，手机用"。

🎯第一步：选平台

根据你想做什么，选不同的平台：

📐 想做完整App / 网站（带登录、数据存储）

Lovable（推荐首选） 免费起步

地址：lovable.dev

最推荐给零基础的人。你说一句话，它直接生成完整App，自带登录、数据库、部署一条龙。代码质量高，能直接交给工程师继续维护。

免费：每天5条消息额度。付费$25/月不限量。

Bolt.new 免费起步

地址：bolt.new

出原型最快，适合想快速看效果的人。浏览器里直接运行，不用配环境。但后端功能不如Lovable完善。

免费：每天300K token。付费$20/月起。

🎨 想做网页界面 / UI设计

v0（Vercel出品） 免费起步

地址：v0.dev

设计感最强，适合做落地页、展示页、管理后台界面。生成的代码质量极高，可以直接拿去给工程师用。

免费：每月有额度。付费$20/月起。

💻 想学写代码 / 想深度定制

Trae（字节出品） 永久免费

地址：trae.ai

这就是你朋友做购物审批站用的工具。完全免费，中文支持最好，适合想从头到尾自己掌控代码的人。需要安装到电脑上，有一点学习门槛。

免费：基础功能永久免费。

豆包MarsCode 完全免费

地址：marscode.com

浏览器打开就能写，不用装任何东西。支持100多种编程语言，还能和飞书联动，适合纯新手体验。

📊 不想碰代码，只想做个工具用

Softr + Airtable 免费起步

地址：softr.io

完全不写代码。Airtable当数据库（像Excel），Softr当界面。拖拽搭出会员系统、库存管理、项目看板等。适合做内部管理工具。

Bubble 免费起步

地址：bubble.io

最老牌的无代码平台，功能最全。现在加了AI生成功能，描述需求就能生成应用。适合做复杂逻辑的App。

📝第二步：实操步骤

路线A：用 Lovable 做完整App（最简单）

  1. 打开 lovable.dev，注册一个账号（Google或GitHub登录）
  2. 点"Start Building"，用中文描述你要做什么。比如："做一个读书笔记App，能记录书名、作者、笔记内容、评分，按日期排序，深色风格，手机优先"
  3. 等AI生成，大约30秒-1分钟，会生成完整界面+数据库+登录
  4. 看效果不满意就继续说，比如"加一个搜索框""改成粉色主题""增加导出功能"，AI会接着改
  5. 点"Publish"发布，会给你一个网址，直接分享给朋友用
  6. （可选）绑定自己的域名，在设置里输入域名，Lovable帮你配置
需求描述模板："做一个【什么App】，有【功能1】【功能2】【功能3】，用户可以【操作1】【操作2】，【风格要求】，【设备要求】"

路线B：用 Trae 从零搭（最灵活）

  1. 下载安装 Trae：去 trae.ai 下载对应你电脑系统的版本，安装
  2. 新建项目：打开Trae，新建一个文件夹作为项目目录
  3. 用中文描述需求：在对话框里详细描述你要做什么，越详细越好。比如"做一个HTML单页应用，功能是XXX，用深色主题，要手机适配，数据用localStorage存储"
  4. AI帮你生成代码：Trae会自动创建文件、写代码，你只需要看结果
  5. 需要数据存储：注册 supabase.com（免费），创建项目，把URL和Key告诉AI，AI帮你接入
  6. 需要上线：注册 github.com，把代码推上去，用 GitHub Pages 免费获得网址
  7. 后续修改：直接在Trae里跟AI说"改成XXX"，AI修改后推送，网站自动更新
注意：Trae需要装在电脑上（Windows/Mac），不能在手机上用。如果只想在手机上操作，选路线A。

路线C：用 Softr 做管理工具（完全不碰代码）

  1. 注册 airtable.com，创建一个表格，像填Excel一样填入你的数据字段
  2. 注册 softr.io，选"Create New App"
  3. 连接Airtable，选你刚创建的表格
  4. 选模板或用AI生成，Softr会根据你的数据自动生成界面
  5. 拖拽调整，改文字、颜色、布局，全部可视化操作
  6. 发布，获得网址，分享给别人用

💰第三步：费用一览

大部分AI工具都是"免费起步+付费扩容"模式，对个人使用来说基本可以零成本：

项目 免费额度 付费起步 什么时候需要付费
Lovable 每天5条消息 $25/月 每天5条够日常迭代，正式运营才需付费
Bolt.new 每天300K token $20/月 做大型项目token不够时
v0 每月有额度 $20/月 频繁生成UI时
Trae 永久免费 — 个人使用不需要付费
豆包MarsCode 完全免费 — 个人使用不需要付费
Supabase（数据库） 500MB存储 $25/月 数据量超过500MB时
GitHub Pages（网站托管） 完全免费 — 个人项目不需要付费
Netlify（网站托管） 100GB/月流量 $19/月 流量超100GB时（很难超）

结论：个人用、朋友圈用、小项目，全程零成本完全没问题。只有当用户量大了、需要自定义域名了，才考虑付费。

⭐写给零基础朋友的5条黄金法则

1. 需求要具体
❌ "做个好用的App"
✅ "做一个记账App，能记收入和支出，有分类标签，底部有5个Tab栏，深色主题"
2. 分步走，不要一口吃成胖子
先做最核心的功能，跑通了再加功能。别第一次就要求做10个页面的完整系统。
3. 不满意就继续说
AI做出来的东西不完美很正常，直接说"这里不对，改成XXX"，AI会迭代修改。一般3-5轮对话就能达到满意。
4. 找参考
看到喜欢的App或网站，截图发给AI说"我要类似这样的"，比纯文字描述效果好10倍。
5. 做不出来别硬扛，换个平台试
每个AI平台各有强项，Lovable做不出来的问题Bolt可能秒解。多试几个，找到顺手的就是了。
